# Week 4 — JPA 연관관계 & 도메인 모델링

## 1. 학습 목표
- 1:N, N:1 연관관계 매핑을 이해한다.
- 양방향 연관관계의 장단점을 이해한다.
- 영속성 컨텍스트, 지연 로딩(LAZY)에 대한 감을 잡는다.

---

## 2. 과제 설명: 회원–게시글 도메인 모델링

### 2-1. 요구사항
- 한 명의 회원(User)은 여러 게시글(Post)을 작성할 수 있다.
- 게시글에는 작성자 정보가 포함되어야 한다.

### 2-2. 엔티티 구조
- User
    - id, email, name, posts(1:N)
- Post
    - id, title, content, author(N:1)

양방향 예시:
- `User.posts` + `Post.author`

---

## 3. 구현 요구사항
- Fetch 전략은 `LAZY`로 설정한다.
- 연관관계 주인을 명확히 지정한다 (`@ManyToOne` 쪽이 주인).
- 게시글 상세 조회 시 작성자 이름을 함께 반환하는 API 구현.

예:
- `GET /api/v1/posts/{id}` → `title`, `content`, `authorName`

---

## 4. 제출 방법
1. `feature/week04-{이름}` 브랜치 생성
2. 엔티티 연관관계 매핑

PR 본문:
